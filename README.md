# StudyMate

StudentPlatonus — студенттерге оқу тапсырмаларын басқаруға арналған веб-сайт.

## Жоба туралы

StudentPlatonus студенттерге оқу тапсырмаларын, дедлайндарды және оқу прогресін бір жерде басқаруға көмектеседі.

## Мүмкіндіктер

- Тапсырмалар тізімі
- Тапсырма қосу
- Тапсырманы өшіру
- Тапсырманы орындау
- Тапсырмаларды іздеу
- Тапсырмаларды сүзу
- Профильді өзгерту
- LocalStorage
- Адаптивті дизайн
- Мобильді навигация
- Форма валидациясы
- Оқу прогресін көрсету

## Технологиялар

- HTML5
- CSS3
- JavaScript

## Файлдар

- script.js
